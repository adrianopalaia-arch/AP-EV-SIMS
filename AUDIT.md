# Baseline audit and roadmap

Scope: the GitHub repository cloned successfully but was empty. The supplied ZIP is the entire available baseline; no existing production model was replaced. All text/source files were read before editing. Bundled bytecode is not source evidence.

Inventory: root `.gitignore`, README.md, INTEGRATION_PLAN.md, CODEX_INTEGRATION_PROMPT.md, RESEARCH_NOTES.md, pyproject.toml; examples/candidates.csv; tests/test_engine.py; src/ap_evsims/{__init__,odds,calibration,schemas,screening,portfolio,parlay,ledger,cli}.py; providers/{base,config}.py. ZIP also contains __pycache__ bytecode for these modules and tests.

Modules: odds conversion/de-vig/EV in odds.py; calibration metrics and caller-authenticated reports in calibration.py; timestamp and pregame/live gates plus unit-based fractional Kelly in screening.py; per-card event/shared-risk caps in portfolio.py; supplied joint-probability evaluation in parlay.py; untyped JSONL in ledger.py. There is no simulation, sport forecast, actual correlation estimation, bankroll account, historical snapshot store, provider implementation, database, API, UI, deployment config, or results reconciliation.

Baseline: 11 unittest tests passed with PYTHONPATH=src and a workspace TEMP/TMP. Initial system Python alias could not execute; initial bundled-runtime run had a sandbox temporary-directory permission error in the ledger test, resolved without source changes.

Critical risks: CSV callers can authenticate arbitrary metrics; validation dates are unused; features default to a generic data timestamp; naive times silently inherit host timezone; a 30-second future quote/data tolerance admits unavailable information. Outputs omit model version, fair odds, and timestamps. Opposite quote has no independent timestamp/market identity. Nonfinite/malformed input can crash or contaminate decisions. Validation aggregate scores do not establish calibrated uncertainty or statistical superiority. No push/void handling: binary EV is unsuitable for integer lines without a settlement model. Units are treated as bankroll in Kelly; no persistent exposure, reservations, duplicates, cash/bonus distinction, or settlement state. Ledger is not wired to CLI and allows recorded timestamp override. Parlays trust an unverified point probability. Feature names are lists, not enforced contracts. No empirical evidence supports profitability.

Priority roadmap: (1) authenticated immutable validation evidence, complete temporal provenance, persistent atomic exposure, historical as-of storage, fixtures and enforced CFB/NHL contracts; (2) timestamped provider adapters and reproducible rolling-origin evaluation with paired market baseline, uncertainty coverage, calibration intervals and settlement-aware forecasts; (3) CFB spreads/totals first, NHL shots/goalie/team next, NFL sides/totals/usage then MLB pitcher/hitter props; (4) shared scenario correlation and portfolio stress/drawdown controls; (5) prospective paper evaluation and operational monitoring. No automatic wagering.
